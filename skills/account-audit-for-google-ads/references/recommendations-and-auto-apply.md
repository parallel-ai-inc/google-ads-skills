# Recommendations and auto-applied recommendations

Written by hand. To be re-read against the source before release.

Everything on this page is **Official**. The Google page below was read on 2026-11-13. The facts on optimization score and Change history are restated from `reporting-and-diagnostics.md`, which names its own pages.

Source: Google Ads Help, "About applying recommendations automatically", https://support.google.com/google-ads/answer/10279006

## How auto-apply works

- When "Automatically apply recommendations" is on, the chosen recommendations apply regularly. Google checks daily which are eligible.
- It is set at the account level only, per recommendation type. Types can be chosen in bundles ("Maintain your ads" or "Grow your business") or one by one in each category.
- A recommendation applies only when it is relevant, so some types apply often and others never.
- The queue on the main Recommendations page shows what will run on a given day. A recommendation in the queue can be dismissed.
- The "Manage" and "History" tabs show which types are opted in and what was applied recently. Change history shows each applied recommendation.
- Auto-apply never raises a budget.
- Since January 26, 2026, "Add responsive search ads" no longer suggests or applies new responsive search ads, and it is gone from the auto-apply settings.
- Google's own note: with keyword insertion in an ad, search terms not covered by negative keywords can appear in the ad text. With auto-apply on for "Add keywords", ad groups that use keyword insertion do not take keywords automatically.

## Optimization score and Change history

From `reporting-and-diagnostics.md`:

- Optimization score is Google's 0 to 100% estimate of how well the account is set up. Applying or dismissing every recommendation both reach 100%. It is a list of open suggestions, not a measure of performance.
- Auto-applied changes show in the recommendations History tab and in Change history. Check them before blaming an unexplained change on the team.
- Change history covers 2 years. System edits can appear as "Google Ads system", and some account level changes may be missing.
